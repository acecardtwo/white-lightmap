# white-lightmap
minecraft resource pack - white block lightmap

Documentation so i won't forget how i did it

• Modified sky light output a bit to prevent skylight color overriding on block light sources, preventing weird lightning artifacts when placed light sources outdoors at night.

• Ignored block tint calculations and force white color output.
